## 实际模型与外部网页

使用已配置的 `https://cf.api.fan/v1`、`gpt-5.6-sol`、Responses 流式传输适配器。网页使用默认 Bing 公开搜索与登记专题来源，未配置搜索服务密钥。

- 发现并修复规划 Schema 的过紧字段上限：模型合理列出的状态需求超过旧上限。现在允许完整字段集合，并向一次修复提供具体校验错误类型。
- 发现并修复通用游戏首页被当成策略正文：现在拒绝首页/购买页等入口，并检查正文主题相关性，同时读取相关专题来源。
- 真实获取了 Rustafied 建筑指南与 Facepunch 的 `Upgrade hard, raid harder` 正文，保存了来源、哈希和抓取时间。搜索无可用可信结果时明确显示直接资料回退；没有声称搜尽最新资料。
- 缺少玩家档案时，模型返回具体观测步骤与条件，而不是宣称当前资源足够。一次成功观测建议请求约 35 秒；该数字是单样本，不能代表延迟分位数。
- 浏览器最终验证关联测试档案后，根据入口未确认封闭和离线安排优先建议核对并加固入口，同时给出科技推进替代方案。请求约 58 秒、无结构修复，引用建筑指南原文，保留官方工作台更新正文；界面明确显示搜索回退与版本未核验。
- 页面刷新后保留建议、状态版本与证据记录；展开区显示来源链接、留存快照与逐字引用。浏览器未记录 JavaScript 错误。界面截图见 [advice-verification.jpg](advice-verification.jpg)。

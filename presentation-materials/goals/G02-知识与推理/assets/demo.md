# G02 / G06 共享演示入口

## 前置条件与证据身份

在仓库根目录运行，使用已有依赖环境和独立演示数据库。固定快照为 `rustdata-pc-vanilla-2026-11-01`，build未知；没有独立Rust专家认证。结构化命令与知识解释不需要模型密钥。真实截图识别仍需要视觉配置，本材料没有新启动付费识图实验。

`representative-io.json` 是本地应用HTTP/SSE采集，问题与数据库是合成的，不是游戏录像。请求走真实应用与计算器，模型替身一旦被调用就失败。文件不保存会话ID、密钥或私人数据。

## 无模型演示主线

```sh
COACH_DATABASE_PATH=data/knowledge-material-demo.sqlite3 uv run uvicorn rust_coach.app:create_app --factory --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`，按顺序输入：

1. `/knowledge C4配方是什么`。观察材料、工作台和来源限制。
2. `/calc {"operation":"raid","target":"building:base-wall:stone","hp":250,"methods":["explosive.timed"]}`。本例仅指定C4，观察公式 `ceil(250 / 275) × 1 = 1`；不能把它说成全方案最优。
3. `为什么250血还需要一颗C4`。观察目标伤害、取整说明与版本限制；无模型配置时可加 `/knowledge` 前缀发送。
4. `/knowledge 最新版本C4配方是什么`。观察明确未认证，而非返回旧数值冒充最新。
5. `/knowledge 主机版C4配方是什么`。观察适用范围阻断。

当前材料并无浏览器截图。以上是可复现步骤，只有保存的HTTP/SSE记录和测试可以标注“已验证”；不要将演示建议写成已完成UI验收。

## 复现本地输入输出采集

```sh
uv run python 'presentation-materials/goals/G02-知识与推理/assets/capture-demo.py'
```

命令在临时数据库中发起正常查询、计算、反馈、撤回、重放和发布回退，将安全摘录打印到标准输出；临时数据库随后清理。不会操作日常数据库，也不使用已有密钥。重新采集会产生新的时间，不能覆盖历史统计后继续沿用旧版本声明；按来源清单另记当前hash。

## 可选截图接入展示

已人工标注的输入图可以复用[G07库存图](../../G07-效果验证/assets/inventory-wide.png)。它只证明有这张输入图，不证明当前模型能正确识别。准备演示时，使用视觉配置上传它，依次问制作缺口、改拆石墙、补250血、追问依据，保留完整输出和失败。

当前测试主线使用合成图及硫磺100的视觉返回，制作目标是火药；不要把测试称为真实C4背包识别成功。真实截图场景的说明与共享数据流可以复用，识图效果需要单独验证。

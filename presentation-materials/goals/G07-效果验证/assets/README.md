## 数据与讲解素材

| 素材 | 内容 | 使用方法 |
|---|---|---|
| [representative-cases.json](representative-cases.json) | 5个代表案例的真实问题、人工标注、模型观测、采用库存、缺口、回答全文及检查引用 | 以 `case_id` 选择；`assistant_verbatim` 逐字保留；其他字段是有来源指针的节选，不冒充完整日志 |
| [evaluation-runs.csv](evaluation-runs.csv) | 全部9次运行的执行、质量、证据、覆盖状态和分组 | 画案例计数；一行是一次运行，不是一轮对话 |
| [evaluation-turns.csv](evaluation-turns.csv) | 12轮聊天HTTP耗时与原报告定位 | 单位秒；零起始轮次；不含探测与初始化 |
| [model-calls.csv](model-calls.csv) | 19次调用的角色、状态、耗时和usage | `-1`轮次代表探测；不要与聊天耗时直接相加 |
| [chart-data.json](chart-data.json) | 汇总、分母、单位、统计方法与绘图限制 | 与CSV交叉核对；不要自动生成准确率或模型优化曲线 |
| [data-flow.mmd](data-flow.mmd) | 与设计说明完全一致的Mermaid源图 | 实线传递数据；虚线是控制；可后续按版面简化重绘 |
| [source-manifest.json](source-manifest.json) | 原有未提交状态、源码／证据哈希、核验时刻 | 版本审计；列出的HEAD不能单独重建当前实现 |
| [verification.txt](verification.txt) | 本次本地测试与只读证据核验记录 | 软件测试与历史模型结果分开表述 |
| [demo.md](demo.md) | 可复现演示顺序、条件与命令 | 默认不重新调用模型、不需要API密钥 |

样例去除了会话ID、附件ID、提示正文及服务端点；没有复制 `.env`、密钥或个人记忆数据库。原始评测报告仍由项目 `evals/` 保存，素材通过相对路径及哈希追溯。五个样例用于讲故事，完整九例CSV用于避免选择性展示。

## 后续制稿注意

输入图可以裁切放大，但需标注裁切，保留完整原件。若把JSON中的对话重排成聊天卡片，应标注“已保存真实回答的排版摘录”，不能当作已录制的浏览器截图。数据单位、待核验标签和样本范围必须随图保留。

本目录未包含游戏规则认证、独立盲评或新版本收益实验；这些缺口见 [补采清单](../evidence.md#补采清单)。
